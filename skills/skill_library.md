# EKO Skill Library

## Core Skills

### 1. Research
- **Description**: Research any topic using web search and AI analysis
- **Steps**: Identify topic → Search sources → Extract key info → Summarize
- **Use When**: Learning new topics, market analysis, competitor research

### 2. Trading
- **Description**: Execute crypto trades and arbitrage
- **Steps**: Analyze market → Identify opportunity → Execute trade → Log profit
- **Use When**: Market gaps exist, profitable opportunities available

### 3. Code Optimization
- **Description**: Analyze and optimize code performance
- **Steps**: Profile code → Identify bottlenecks → Optimize → Test → Deploy
- **Use When**: Performance issues detected, efficiency needed

### 4. Market Analysis
- **Description**: Identify market gaps and opportunities
- **Steps**: Scan markets → Analyze trends → Identify gaps → Plan solution
- **Use When**: Looking for new revenue streams

### 5. Self-Evolution
- **Description**: Learn from experience and improve
- **Steps**: Review performance → Identify improvements → Implement → Verify
- **Use When**: Continuous improvement needed

## Advanced Skills

- **Use When**: Physical infrastructure needed

### 7. Patent Generation
- **Description**: Generate patentable ideas
- **Use When**: Innovation identified

### 8. Scientific Discovery
- **Description**: Generate and test hypotheses
- **Use When**: Research opportunities exist
